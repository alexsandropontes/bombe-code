# Chatbot POC - Node.js + React

## Quick Start

### 1. Configurar
```bash
cp .env.example .env
# Editar .env com chaves de API
```

### 2. Backend (Node.js)
```bash
cd backend
npm install
npm run dev
```

### 3. Frontend (React)
```bash
cd frontend
npm install
npm run dev
```

### 4. Acessar
http://localhost:5173

## Estrutura
```
chatbot/
├── backend/      # Node.js API
├── frontend/     # React UI
├── agents/teams/ # Times de agentes
└── .env
```
