# EP-06: LocalModelManager & Gestor de Ciclo de Vida de Modelos Locais

## 1. Declaração do Problema
O compartilhamento de uma única GPU (16GB) para múltiplos modelos de linguagem gera falhas críticas de `CUDA Out of Memory` se dois servidores forem acionados simultaneamente ou se um processo anterior deixar alocações zumbis na VRAM. É imperativo um gestor centralizado que aplique concorrência zero (Fila Indiana) e verifique a limpeza da memória antes de subir qualquer modelo.

## 2. Valor de Negócio
Garante estabilidade absoluta nas rotinas de engenharia de software automatizadas pelo Bombe Code, eliminando intervenções manuais para matar processos órfãos do `llama-server`.

## 3. Escopo
### In Scope
- Criação da classe `LocalModelManager` para gerenciar o ciclo de vida do `llama-server`.
- Integração direta com o binário `b11985` compilado com suporte a CUDA 13.2.
- Implementação do porteiro de VRAM (`VRAMGate`) inspecionando `nvidia-smi` com tolerância máxima de 300MiB livres antes de inicializações.
- Polling resiliente no endpoint HTTP `/health` com timeout configurável.
- Encerramento gracioso com `SIGTERM` e escalonamento para `SIGKILL`.

### Out of Scope
- Configuração de modelos remotos (OpenAI, Anthropic).
- Treinamento ou fine-tuning de modelos.

## 4. Stories Relacionadas
